============================================================
1. PRODUCT VISION
============================================================

The application is an AI-powered interactive short-story co-writer.

The user creates a story by entering:
1. Story title
2. Genre
3. Tone
4. Premise

After clicking "START WRITING":
- The story is created/persisted.
- The AI generates the opening scene.
- The application navigates to the story workspace.
- The workspace uses a genre-specific visual theme based on the selected genre.
- The AI provides exactly 2–3 possible plot directions after each ready scene.
- The user chooses a direction.
- The AI generates the next scene.
- The story continuously grows as a branching tree.
- Previously generated scenes and branches are NEVER deleted just because the user navigates backward.
- The user can navigate to any previous generated scene.
- From an earlier scene, the user can select a different unexplored choice and create a new branch.
- Already explored choices reuse their existing child scene and must NOT trigger another AI generation.
- The complete story tree remains intact throughout exploration.
- When the user reaches a satisfying ending / completes their story, they can use "STORE STORY".
- Storing creates a saved copy/version of the story in a "Generated Stories" library/folder.
- The saved copy preserves the complete explored tree, metadata, genre, tone, premise, scenes, choices, and relevant active state.
- Opening a stored story must restore its complete tree and automatically restore the UI theme associated with its saved genre.
- The user can continue exploring an opened stored story where appropriate.
- The user can export the currently active linear path as Markdown or PDF.
- Export must contain only the root-to-active-scene path and must not expose internal branching metadata or AI prompts.

The application should feel like:
"Enter a story world → explore it → branch it → travel backward → create alternate paths → preserve the entire tree → store the story → reopen the same story world later."

============================================================

- no scenes deleted
- no choices deleted
- no branch relationships changed
- no AI generation

- no duplicate generation
- existing child is reused

- generate exactly one child
- persist it
- update tree
- set it active

When the user stores the story:
- preserve the full tree
- preserve genre
- preserve active state
- do not collapse the story into a single path
